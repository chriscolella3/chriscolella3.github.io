Details

I've always wanted to get into game development and once I realized nothing was holding me back from starting, this project was born.

I initially set out to make an idle game, but it quickly turned into a idle tower defense hybrid.

Since I started working on this game, I've also detailed my journey in my own personal dev blog that has been covering everything since I started development.

Summary

The game I've been working on is an idle tower defense. You are a tower that sits in the center of the screen, defending itself against waves of enemies that spawn all around you attempting to destroy the tower. You have various upgrades, weapons, and perks at your disposal that you can use to help you survive as many waves as possible.
